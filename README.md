# Learn Deep Learning with Phoebe

Six sessions on neural nets from the ground up: the neuron on paper, backprop by hand, a real network trained live in the browser, the architectures that ate vision, the taming discipline - and an honest showdown against gradient boosting on byte-identical data.

**Live:** https://phoebefu6.github.io/learn-deep-learning-with-phoebe/

- `assets/dl-live.js` is a genuine in-browser MLP: real forward/backward passes, live decision-boundary heatmap, and a tabular showdown on the exact seeded Mango Lane sample the ensemble-methods course uses
- Measured canon: XOR falls to 9 parameters; the spiral separates capacity from optimization (55% stuck, 100% solved by the optimizer alone); nets top out at 68% holdout vs the tuned booster's 73 on identical data
- Every research claim verified to source, misquote watchlist taught as content: `materials/official-course-map.md`
